BillGuard User Guide

Introduction

BillGuard is a small home network scanner made by Pond Provisions. It looks at the devices on your network and tells you which ones need attention.

What You Need

Before you start, make sure you have:

  • A computer running Linux, macOS, or Windows
  • Python 3.10 or newer
  • Permission to scan the network you are on

Installation

Install BillGuard with pip:

pip install billguard

Check that it worked:

billguard --version

Quick Start

Run your first scan on the default pond:

billguard scan --pond home

BillGuard prints each device it finds, along with a status of ok, warn, or splash.

Scan Modes

Use --mode to choose how deep a scan goes.

  • shallow: lists devices only. Takes seconds.
  • normal: adds open ports. This is the default.
  • deep: adds weak password checks on devices you own.

Troubleshooting

If BillGuard finds no devices, confirm you are connected to the network and that your firewall allows local scans. If a device shows splash, change its default password first.

Reference

Commands: scan, report, pond list. Run billguard --help for every option.
