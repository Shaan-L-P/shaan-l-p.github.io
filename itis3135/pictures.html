Everything Pictures

This page explores how digital images behave on the web. By comparing image formats, file sizes, resizing methods, and incorrect proportions, I can see how editing an image affects its appearance and storage requirements. The first section uses a red Toyota Supra MK4 photograph from Pexels, and the second uses a photograph I took of a round wireless charger next to my face.

Red Toyota Supra MK4: Image Formats, Resizing, and Proportions

I chose this red Toyota Supra MK4 photograph because its glossy bodywork, distinctive headlights, reflections, and background provide plenty of fine detail to compare. The supplied filename identifies the Pexels source as photo 9819403 and the contributor as Alex the Photographer. The Pexels profile identifies the photographer as Alexandr Ivanov and links to a gallery of other photographs. The uploaded JPEG is portrait-oriented and measures 1365 x 2048 pixels. Its file size is 515,317 bytes (0.4914 MiB), which is smaller than the approximately 5000 x 3000-pixel image suggested in the assignment.

Downsizing Images with CSS

This example displays the original image at 20% of its original width. The height is set to auto, so the browser preserves the original proportions. CSS changes only the displayed size; the original file remains 1365 x 2048 pixels and 515,317 bytes (0.4914 MiB).

Proper Reduction of Image with an Editor

This copy was resized in an image editor to 600 pixels wide while preserving the original aspect ratio. Its dimensions are 600 x 900 pixels and its file size is 124,780 bytes (0.1190 MiB). This creates a new, smaller image file, unlike CSS downsizing, which only changes the displayed size.

Improper Enlarging with CSS

The first image uses the properly resized 600 x 900-pixel file. The second uses a copy reduced to 25% of those dimensions. Both are displayed using the same CSS sizing rules.
