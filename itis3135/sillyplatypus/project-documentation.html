Silly Platypus | Project Notes

A record of the site's features, intended audience, and final-project requirements.

Silly Platypus Creekside Discovery Co. is a fictional neighborhood shop offering creek exploration kits, freshwater wildlife guides, and simple nature activities. The website is intended to help families, students, and beginning nature explorers understand the shop's products, sample hours, fictional location, and ways to get started.

Silly Platypus Is Designed Around Its Visitors

Visitors need to understand the available activities quickly, find the information that helps them plan a visit, and feel comfortable exploring even if they are new to nature journaling. The navigation separates the shop's story, products, hours, location, purpose, instructions, and interactive tools.

The site does not collect orders, payments, or personal information. Journal entries created on the Activities page stay in the current page session. The kit planner uses sample prices only, and the location and business details are clearly presented as fictional.

Silly Platypus Project Specifications

  • Multi-page structure: Home, About, Products, Hours, Location, Why, How, Activities, and Project Notes.
  • Shared components: Every site page loads the same header and footer from the components folder.
  • Consistent branding: Silly Platypus appears in each page title and main page heading. The shared header and footer use the same italic tagline.
  • Responsive design: The existing stylesheet uses a consistent palette, multiple font families, and responsive layouts.
  • Accessibility: Pages include a skip link, semantic landmarks, descriptive image text, labeled form controls, and live status messages for interactive updates.
  • Validation: The Accumulus script and course standards checker are included on the pages.
  • Designer credit: The shared footer credits Shaan Patel.

Silly Platypus Dynamic Functionality

  1. Activity Finder: Filters activity cards by setting and experience level, then reports how many suggestions match.
  2. Field Journal: Adds observation entries to the page and allows visitors to remove individual entries. Entries are temporary and are not uploaded.
  3. Kit Planner: Calculates a sample total and updates an itemized list when a starter kit or optional supplies are selected.

Silly Platypus Use of AI Tools

ChatGPT was used to help plan the added interactive features, organize the project requirements, and draft JavaScript and supporting page content. The generated suggestions were adapted to the existing Silly Platypus folder structure, components, writing, and visual theme rather than replacing the original site.

The new code is organized in a separate activities script, uses descriptive names and comments, and updates the page through DOM methods. The final pages should still be checked with the course validators and tested in a browser before submission.
