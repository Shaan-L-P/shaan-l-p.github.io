Where This Is All Headed

By this point in the semester I've built out several separate but connected corners of the web, each one serving a different purpose but all tied back together through links. Rather than cramming everything into one page, the goal has been to keep personal, academic, and professional content cleanly separated while still making it easy to move between them.

This course site in particular exists to document that process. It's where my coursework, assignments, and reflections for ITIS 3135 live, and it links out to my other projects so anyone visiting can see how the whole structure fits together.

Tools and Resources

Throughout the development process, I've used Visual Studio Code (VS Code) as my primary code editor and Emmet to speed up writing HTML and CSS. These tools make it easier to organize code and build pages more efficiently. I also use Professor von Briesen's teaching site as a resource for course materials, examples, and assignment guidance.

My Websites and Projects

The following sites and projects make up the different parts of my web presence and coursework:

  • Personal Home Page: Sits at the root of my webspace account and works as my general landing page and portfolio, separate from any single class.
  • Course Site: Lives inside the itis3135 folder and holds everything built specifically for this class, including my introduction, assignments, and reflections.
  • Design Firm Site: A separate site inside its own folder, built to look and feel like a real freelance design business rather than a class assignment, with its own distinct branding and layout.
  • CRAPpy Page: A deliberately poorly designed page that demonstrates common design problems and provides examples of what to avoid when building a website.
  • Whimsical Product Company Site: A creative website concept for a fictional product company, giving me an opportunity to experiment with branding and a more playful design.
  • Client Project Site: A website project focused on meeting a client's needs and presenting information in a useful and professional way.
