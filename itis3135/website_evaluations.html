Website Evaluations

For this assignment, I chose two websites to evaluate using the CRAP principles: Contrast, Repetition, Alignment, and Proximity. One website is well-designed and easy to navigate, while the other is poorly designed and difficult to use. By comparing the two, I examined how each website uses these four principles and how its design choices affect the overall user experience.

GOV.UK

  • Contrast: Dark text sits on a plain white background, so everything is easy to read. Links are a clear blue and the main buttons are a bright green or black, so you always know what to click.
  • Repetition: The same font, spacing, link style, and button style show up on every page. Once you have used one page, the rest feel familiar right away.
  • Alignment: Almost everything lines up along a strong left edge, with a simple grid behind it. Headings, paragraphs, and lists all follow it, which keeps the page calm and easy to scan.
  • Proximity: Related items are grouped together with plenty of white space between groups. A heading sits close to the text it introduces, so it is obvious what belongs with what.

Ling's Cars

  • Contrast: There is a lot of contrast, but it is the wrong kind. Neon colors, flashing text, and loud backgrounds all fight each other, so nothing stands out as the most important thing and some of the text is hard to read.
  • Repetition: There is repetition in the sense that everything is loud, but there is no consistent system. Fonts, colors, and sizes change constantly, so the page has no real visual identity tying it together.
  • Alignment: Elements look scattered across the page with no clear grid or edge to follow. Text and images sit at random spots and sizes, which makes it hard for your eyes to know where to go next.
  • Proximity: The page is crammed full, so related things are not clearly grouped and unrelated things end up right next to each other. Links, ads, and information blur together, and it is tough to find what you came for.
